☁ Cloud Sync — access live from anywhere

By default your data lives only in this browser — that's why a new download or a different computer looks empty. Connect a free Google Firebase project once, and every device (anywhere in the world) will see the same live data instantly, no re-entering anything.

How to get a free Firebase config (one-time, 5 minutes)
  1. Go to console.firebase.google.com and sign in with any Google account.
  2. Click Add project → give it any name (e.g. your institute name) → keep clicking Continue → Create project.
  3. In the left menu click Build → Firestore Database → Create database → choose a location close to you → start in test mode → Enable.
  4. Click the ⚙ gear icon (top left) → Project settings → scroll to "Your apps" → click the </> (Web) icon → give it a nickname → Register app.
  5. Firebase will show a code block starting with const firebaseConfig = {"{"} ... {"}"} — copy everything inside the curly braces and paste it in the box above.
  6. Click 🔌 Connect Cloud Sync here. Do this same 1-minute paste on every computer/phone your staff use to log in — after that, everyone sees the same live data automatically.
